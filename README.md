# Multi-Parameter Health Monitoring System

## Overview

Health monitoring system developed on STM32F411CEU6.

### Features

- Heart Rate Monitoring (MAX30100)
- SpO2 Monitoring (MAX30100)
- Body Temperature Measurement (DS18B20)
- OLED Display (SSD1306)
- UART Debug Output
- Timer Interrupt Processing
- Moving Average Filtering

### Hardware

- STM32F407
- MAX30100
- DS18B20
- SSD1306 OLED

### Communication Protocols

- I2C
- SPI
- UART
- 1-Wire

### Software

- Embedded C
- STM32 HAL Library
- Interrupt-based Design
